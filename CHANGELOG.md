# Changelog

## [1.1.0] - 2024-01-15 - AI Integration Update

### 🎯 Major Features Added
- **Ollama Integration**: Local AI processing for fast content analysis and sentiment detection
- **OpenRouter Support**: Advanced AI capabilities through cloud-based models
- **Hybrid AI Architecture**: Fallback system that tries local processing first, then cloud

### 🔧 Technical Improvements
- **AIService**: New service that handles both Ollama and OpenRouter
- **Enhanced Sentiment Analysis**: AI-powered content analysis combined with traditional sentiment scoring
- **Smart Bounty Generation**: AI-generated bounty titles, descriptions, and announcements
- **Dynamic Reward Messages**: Personalized reward messages generated by AI

### 📦 Dependencies Updated
- Added `ollama` package for local AI integration
- Added `uuid` package for unique ID generation
- Updated environment configuration for AI services

### 🛠️ Configuration Changes
- **New Environment Variables**:
  - `OLLAMA_URL`: URL for local Ollama service (default: http://localhost:11434)
  - `OLLAMA_MODEL`: Model to use for local processing (default: llama2)
  - `OPENROUTER_API_KEY`: API key for OpenRouter service
  - `OPENROUTER_MODEL`: Model to use for advanced analysis (default: anthropic/claude-3-haiku)
- **Removed**: `OPENAI_API_KEY` (replaced with Ollama/OpenRouter)

### 🧪 Testing & Development
- Added `npm run test:ai` script to verify AI service configuration
- Comprehensive test script for both Ollama and OpenRouter
- Better error handling and troubleshooting guidance

### 📚 Documentation Updates
- Updated README.md with new AI setup instructions
- Enhanced SETUP.md with detailed Ollama installation guide
- Added OpenRouter configuration steps
- Updated troubleshooting section

### 🚀 Performance Improvements
- **Local-first processing**: Ollama handles most content analysis locally for speed
- **Intelligent fallback**: OpenRouter used for complex analysis when local processing fails
- **Reduced API costs**: Local processing reduces dependency on expensive cloud APIs
- **Better analysis quality**: Advanced models provide more nuanced content understanding

### 💡 New Capabilities
- **Theme detection**: Better identification of content themes and trends
- **Spam detection**: AI-powered spam and low-quality content filtering
- **Content quality scoring**: Objective quality assessment of user contributions
- **Contextual responses**: More natural and contextual reward messages
